# Authenticated asymmetric UDP link

راهنمای کامل فارسی: [README_FA.md](README_FA.md)

Version 0.3.0 is a standalone, standard-library Python research prototype for carrying authenticated UDP datagrams over separately routed uplink and downlink paths. The live runtime only binds to source addresses assigned to the host; it does not transmit forged-source raw packets.
